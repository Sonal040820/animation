# Public tools evaluated for the Blender studio

These are **references**, not an instruction to install arbitrary scripts from the internet or download assets without rights.

## Verified in actual GitHub environment
- Blender 4.5.16 LTS official Linux x64 binary, SHA256 checked.
- Blender Cycles CPU render engine; glTF, FBX, OBJ, Alembic, USD operators.
- VRM Add-on for Blender v4.10.5 by the official maintainer, SHA-256 pinned, vrm import operator registered headlessly.
- Blender studio tools in this repo: license-gated imports, bone-map validation, IK target attachment, shot contracts and render profiles.

## Available but not yet connected or installed
- Rigify (Blender Extensions official listing currently availability-restricted): investigate a compatible, reviewed package before enabling.
- Mixamo: free animation library with Adobe use/redistribution restrictions; requires user-specific account access.
- Poly Haven, ambientCG, Kenney: CC0 environment, texture and prop libraries; individual asset downloads happen when needed, not in this setup.
- Blender Studio rigged characters: inspect each project's license/access before using.
- VRoid Hub: permissions vary per character including violent action and redistribution. No character downloaded.
- Cloud GPU: student's Camber or other eligible credits if redeemed; no GPU endpoint currently configured.
- Private model/artifact storage: provider and credentials outstanding.

Avoid misrepresenting software being installable as a guarantee of high-quality generated actors; art direction and source assets remain separate production decisions.
